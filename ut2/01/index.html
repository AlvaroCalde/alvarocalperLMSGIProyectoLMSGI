Listas anidadas

Definición de listas multinivel o anidadas

Una lista multinivel es caundo en un elemento de una lista, tiene otra lista Sirve para organizar informacion de forma jerárquica. Ejemplo:

  1. Hardware

    • Ratón
    • Pantalla
    • Ordenador
    • Impresora
    • Plotter

  2. Software

    • Office365
    • Visual Studio Code
    • Windows 11
    • NetBeans
    • Google Chrome
